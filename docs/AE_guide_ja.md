# After Effectsでの使い方

## 1. 推奨される初期設定

-   **コンポジション設定**: 素材を `256x192` サイズのコンポジションに配置します。
-   **レイヤー設定**: レイヤーの画質設定を「バイリニア」から「ニアレストネイバー」に変更し、アンチエイリアスを無効にします。

## 2. エフェクトの適用

エフェクトメニューから「MSX1 Palette Quantizer」を適用します。

## 3. 基本的な色味調整

MSX1エフェクトの前に、以下のような調整を適用することが推奨されます。
-   **トーンカーブ**: 全体の輝度を調整します。
-   **シャープネス**: 映像をシャープにします。
-   **彩度**: 彩度を調整します。
-   **LOOK（LUT）**: LUTを適用して特定の色味に近づけます。

## メイン設定
-   **MSX1/MSX2カラー**: MSX1（15色）とMSX2向けの15色パレットを切り替えます。
-   **Dither**: ディザリングのON/OFFを切り替えます。
-   **Dark Area Dither**: 暗い部分に専用のディザパターンを使用するかどうかを選択します。
-   **Convert Algorithm**: 8x1ドット内の2色変換アルゴリズムを5種類から選択します。
    - **None**：何もしません
    - **Fast**：登場回数の多い物2色を使います、高速に動作します。
    - **Basic**：色距離を基に登場する色から2色を選びます。
    - **Best**：15パレットの中から8ピクセル内に登場する色を表すのに最適な2色を選びなおします。（推奨）
    - **Best-Attr**：ベストに加えて周辺上下ピクセルの色も考慮して2色を選びます。
    - **Best-Trans**：ベスト属性に加えて、左右フレームの色も考慮して2色を選びます。
-   **Color Distance**: 色距離の計算方法をRGBまたはHSVから選択します。
-   **RGB Weight**: Color Distance を RGB にした場合に、R/G/B それぞれの距離計算の重みを個別に調整します。
-   **HSV Weight**: Color Distance を HSV にした場合に、HSV空間での色距離計算の重み（色相、彩度、明度(Value)）を調整します。

## 前処理
-   **Posterization（ポスタリゼーション）**: MSX変換前に色段数を制限して色数を減らします（0〜255、初期値16、1以下で無効）。ノイズを抑えたりフラットな塗りを増やしたり、ディザパターンをコントロールするのに役立ちます。
-   **Saturation Boost**: 0で無効、値を上げると彩度を強めます（1で約1.25倍）。
-   **Gamma (Darker)**: ガンマ値を直接指定します（1で変化なし、1より大きくすると中間調が暗く、1未満では明るくなります）。
-   **Contrast Adjust**: 1で変化なし、1より大きいとコントラスト強調、1未満で弱めます。
-   **Hue Rotate**: 色相を -180 〜 180 度の整数値で回転させます。

## パレットコントロール

-   **MSX1 Palette Control**: 16色（透過含む）のうち使用する色だけをチェックボックスで選択できます。非選択の色は量子化対象から除外されます。
-   **Randomize / Rand +1 / Rand -1**: 有効化されている色の組み合わせをランダムに切り替えます（+1/-1は現在の構成から1色増減）。
-   スウォッチ表示は参考用の見本で、直接クリックして色を変えることはできません。

## その他

-   **92 Color**: (開発用) 92色パレットで出力します。
