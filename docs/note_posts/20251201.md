  ### コマンドオプション

  AEプラグインの説明でも述べましたが、入力画像の事前の色調整なしではよい見た目の処理結果はなかなか得られないです。画像処理ソフトや動画編集ソフトでは良しなにそれをやってもらえればいいんですが、コマンド版では前処理のためのオプションを充実させました。

  引数なしでコマンドを実行するかと英語で、 --help-ja という引数で実行すると日本語でコマンドオプション詳細が表示されます。

  ```
  PS F:\test> .\msx1pq_cli.exe --help-ja
  MMSXX - MSX1 Palette Quantizer
  使い方: F:\test\msx1pq_cli.exe --input <ファイル|ディレクトリ> --output <ディレクトリ> [オプション]
  1つの画像またはフォルダ内の複数の画像を受け取り、MSX1(TMS9918)の表示ルールに則った画像
  に変換します。
  オプション:
    --input, -i <ファイル|ディレクトリ>  入力PNGファイルまたはディレクトリを指定
    --output, -o <ディレクトリ>       出力先ディレクトリを指定
    --output-prefix <文字列>        出力ファイル名の先頭に付与する接頭辞を指定
    --color-system <msx1|msx2>   (デフォルト: msx1)
    --dither / --no-dither       (デフォルト: dither)
    --dark-dither / --no-dark-dither (デフォルト: ダークディザーパレットを使用)
    --8dot <none|fast|basic|best|best-attr|best-trans> (デフォルト: best)
    --distance <rgb|hsb>         (デフォルト: hsb)
    --weight-h <0-1> --weight-s <0-1> --weight-b <0-1>
    --pre-posterize <0-255>      前処理でポスタリゼーションを適用 (デフォルト: 16 1以下は処理なし)
    --pre-sat <0-10>             処理前に彩度を高く補正 (デフォルト: 1.0)
    --pre-gamma <0-10>           処理前にガンマを暗く補正 (デフォルト: 1.0)
    --pre-highlight <0-10>       処理前にハイライトを明るく補正 (デフォルト: 1.0)
    --pre-hue <-180-180>         処理前に色相を変更 (デフォルト: 0.0)
    --pre-lut <ファイル>           処理前にRGB LUT(256行のRGB値)や.cube 3D LUTを適用
    --palette92                  (開発用) ディザ処理を行わず92色パレットで出力
    -f, --force                  上書き時に確認しない
    -v, --version                バージョン情報を表示
    -h, --help                   ロケールに応じてUSAGEを表示
    --help-ja                    この日本語のUSAGEを表示
    --help-en                    Show this usage in English
  ```

  全てを解説しませんがコマンドライン版の主なオプションと新規で増えたオプションの使い方だけ解説します。その他はAEプラグインの記事を参照してください。

  **input のフォルダ指定：** 画像のパスでなくフォルダを指定すると中に含まれるpng画像を一括変換します。動画を扱いたいときなどに使います。
  --**output-prefix：** 出力ファイルの接頭語指定ができます。同じディレクトリに違う名前で出力する場合に使います。
  **-f：**出力画像と同じ名前のファイルがすでに存在する場合に上書き確認をしなくなります。
  **--pre-posterize：**前処理でポスタライズ（色の量子化）を行います。色数を少なくして揺らぎやノイズなどを変換時に拾わないようにするものですが、雑に値を替えると出てくる色やディザが変化するのでガチャ的な微調整にも使えます。
  **--pre-sat / --pre-gamma / --pre-highlight：**AE版にもあった彩度上げ・暗部強調・ハイライト強調のパラメータですがONOFFだけでなくその強度が指定できるようになりました。（最新のAE版もそのように修正されてます。）
  **--pre-hue**：色相を回転させます。全体の色合いをずらす処理で180を指定すると完全に補色になります。通常はごく小さい値を指定して、見た目がきれいになる結果を探る際に使います。

  ### LUTでの前処理

  LUT（ラット：ルックアップテーブル）とは適用するだけで画像や映像を映画のようなおしゃれな色合い（だけじゃないけど）に変化させる仕組みで、その際に扱う LUTファイル は中に数字が羅列されたテキストファイルです。このLUTファイルのうち cube形式 をmsx1pq_cli.exeに引数で渡すことができます。

  ```
  msx1pq_cli.exe -i hoge.png -o result --pre-lut lutファイル名.cube
  ```

  msx1pq_cli.exeには色々な前処理用の色彩調整オプションがありますが、前処理を1パラメータで一気に行ってしまおうという目的で使います。例として配布ZIPに含まれている ContrastAndSaturationBoos.cube を使ってみます。

  [![画像](https://assets.st-note.com/img/1764548597-yVWpRYLD9f725ZxwdUe8ShrB.png?width=1200)](https://assets.st-note.com/img/1764548597-yVWpRYLD9f725ZxwdUe8ShrB.png?width=2000&height=2000&fit=bounds&quality=85)

  [![画像](https://assets.st-note.com/img/1764548689-fnxoObFgiwEXSmBrG9kY3IDU.png)](https://assets.st-note.com/img/1764548689-fnxoObFgiwEXSmBrG9kY3IDU.png?width=2000&height=2000&fit=bounds&quality=85)変換結果（Note記事用に2倍に拡大表示）

  このcubeはコントラストと彩度を上げる前処理を行うものです。（今回のサンプル画像ではlut適用しないほうが白が飛んでなくて好みですが）基本設定として使いやすいかと思います。ここにさらに微調整でその他オプションで見た目を調整していきます。

  ## コマンドの使い方（楽々操作編）

  上述のようにコマンドオプションを色々変更してみていい出力結果を探すが基本ではあるんですが、ちょっと面倒くさいです。（AEプラグインの場合はこの試行錯誤がリアルタイムに確認出来て楽なのです。）

  これを楽に使うには、あらかじめオプションを設定した記述のあるbatファイルなどを用意してそこに画像をドラッグ＆ドロップする方法です。お気に入りのオプションが見つかったらbat化しておくといいです。配布ZIP内にはサンプルとして10個のオプション設定で一気に10回の画像変換をするbatファイルが含まれています。

  [![画像](https://assets.st-note.com/img/1764549634-JIU80m9qGDZ6KiyujA2PCnMN.png)](https://assets.st-note.com/img/1764549634-JIU80m9qGDZ6KiyujA2PCnMN.png?width=2000&height=2000&fit=bounds&quality=85)

  png画像（またはpng画像をフォルダ）を run_batch_pipeline.bat にドラッグ＆ドロップすると（batファイルの横にはexeファイルとcudeファイルがある状態で実行してください。）

  [![画像](https://assets.st-note.com/img/1764549904-10PnzrEyVlf7sQqboXDu8AHN.png?width=1200)](https://assets.st-note.com/img/1764549904-10PnzrEyVlf7sQqboXDu8AHN.png?width=2000&height=2000&fit=bounds&quality=85)

  bat ファイル横に out フォルダが作られ中にオプション設定別での10枚の変換結果のpngファイルが含まれているはずです。batファイル内のオプション指定は好きなように書き換えて使ってみてください。

  ## 動画の変換

  msx1pq_cli.exe には入力に動画を受け付ける機能はありません。あらかじめpngの連番などに変換して置いてください。引数にはその連番画像を含めたフォルダを渡します。先ほどのオプション違いの5番の見た目が気に入ったので、run_batch_pipeline.bat を 流用して5番以外の処理を消した type5.bat を用意しました。
