# MSX１エフェクト for アフターエフェクツ/プレミアを公開します



以前作っていたMSX1風画像変換ツール（Python製 コマンドライン版）をベースに、動画編集ソフト上でMSX1(TMS9918)の特徴的な見た目を再現するプラグインを作りました。TMS9918風のドット絵が好きな人でAE・Premiere PROを使う人がどれだけいるのかというと疑問ですがとりあえずここに一人います。なぜ作ったか、フォトショップ版は？みたいな話は別途投稿しますので、とりあえずプラグイン配布と使い方の説明、動画の書き出し手順までを説明します。

## 基本的な色味を調整する

なぜ良い感じの見た目になっていないかと言うと元画像にMSX１で苦手な色があり、そのまま変換しようとしているからです。これをAEやプレミアの基本機能でMSX１風エフェクト適用前の色を調整する事で対応していきます。

### トーンカーブを適用する

まずトーンカーブから。ここではLumetriエフェクトを使いますが色彩調整用ならなんのエフェクトでも構いません。LumetriをMSXエフェクトより前に適用し、トーンカーブを以下のような設定にします。こうするときれいな結果画像になる事が多いです。理由は後述。

[![画像](https://assets.st-note.com/img/1763933760-Xf0apBJOeG6ygjNikWUDq54V.png)](https://assets.st-note.com/img/1763933760-Xf0apBJOeG6ygjNikWUDq54V.png?width=2000&height=2000&fit=bounds&quality=85)

[![画像](https://assets.st-note.com/img/1763958552-Ts758BNQ3lqUZY0OJRwKybx2.png)](https://assets.st-note.com/img/1763958552-Ts758BNQ3lqUZY0OJRwKybx2.png?width=2000&height=2000&fit=bounds&quality=85)

女の子がはっきりしてきました。動画編集ソフト対応にしたことで、このような調整結果を（後続のMSXエフェクトをかけたまま）リアルタイムで確認することができます。コマンド型の画像変換では難しい部分です。

なお元画像そのままの色味の再現はあきらめたほうがいいです。出ない色はどうやってもきれいに出ないので。これを無理に対応してもディザが汚くなったりするだけですので。MSXの表現可能な色空間にいかにして元画像を調整するかがキモです。

### シャープネスを上げる

Lumetriのシャープネス設定を０から30に上げます。元絵にもよりますが境界線があるようなイラストが元画像の場合うまくワークします。

[![画像](https://assets.st-note.com/img/1763934197-7xk2TXvYIGzdyH1Apu4mUc5P.png)](https://assets.st-note.com/img/1763934197-7xk2TXvYIGzdyH1Apu4mUc5P.png?width=2000&height=2000&fit=bounds&quality=85)

[![画像](https://assets.st-note.com/img/1763958594-sot6BGnd9aAHz71qODwLumWy.png)](https://assets.st-note.com/img/1763958594-sot6BGnd9aAHz71qODwLumWy.png?width=2000&height=2000&fit=bounds&quality=85)

キャラの境界線がはっきりしました。もっと値を上げてもいいのですがその分荒れてくる場所もあるので今回はこのくらいにしておきます。単色背景ならもっと上げてもいいかもしれません。

### 彩度を上げる

次に シャープネス設定の下にある自然な彩度を上げます。今回は50にします。元絵の彩度が高いほうが様々なパレットが適切に適用されやすくなります。今回はそこまで変わっていませんが劇的に絵が良くなることはよくあります。

[![画像](https://assets.st-note.com/img/1763958884-fFiSqkh51GT8Y7op6cDMbaIn.png)](https://assets.st-note.com/img/1763958884-fFiSqkh51GT8Y7op6cDMbaIn.png?width=2000&height=2000&fit=bounds&quality=85)

### LOOKを適用する

LOOKの適用（LUT適用）という機能を使ってみます。これは全体の色味を一気に雰囲気良く変えてくれる優れ物のエフェクトです。

[![画像](https://assets.st-note.com/img/1763936114-jM9K7A6m3sPHwlLTDqzfXkoF.png)](https://assets.st-note.com/img/1763936114-jM9K7A6m3sPHwlLTDqzfXkoF.png?width=2000&height=2000&fit=bounds&quality=85)

50個くらいのプリセットがありますが、SL CLEAN KODAK B というものをあててみます。

[![画像](https://assets.st-note.com/img/1763958926-O4LvoHmEtx9qDKGsQzfU26ej.png)](https://assets.st-note.com/img/1763958926-O4LvoHmEtx9qDKGsQzfU26ej.png?width=2000&height=2000&fit=bounds&quality=85)

服と紙のブルーが落ち着きました。空の色と差別化になるので採用します。とりあえず色々なLOOKを適用すると良い結果が出てくることがあります。以下もいい感じです。

[![画像](https://assets.st-note.com/img/1763959000-dA5lr87V3zvhempuNscyBoWa.png)](https://assets.st-note.com/img/1763959000-dA5lr87V3zvhempuNscyBoWa.png?width=2000&height=2000&fit=bounds&quality=85)

モノクロのLOOKをあてると結構かっこいい物が出てきました。

[![画像](https://assets.st-note.com/img/1763957838-Y4kibR3xWmUPeGt6BSQgILC7.png)](https://assets.st-note.com/img/1763957838-Y4kibR3xWmUPeGt6BSQgILC7.png?width=2000&height=2000&fit=bounds&quality=85)MSX1CGの新たな魅力？

その他、好きな方法で色彩調整をして良いです。

今回はやりませんが、特定の色味だけ調整したり、マスクを切って特定の場所だけ色味を替えたりすることもできます。大きなツールに処理を任せた事でこの辺りは至れり尽くせりです。今（2025年11月下旬）ベータの次バージョンのプレミアだとAIを使って自動で動画のマスクを切る事もできるようです。

### 8ドット内2色変換のアルゴリズム指定: 8-dot / 2-color

今回のプラグインの肝となる機能です。ドット絵の出来を左右する大事な部分なので、アルゴリズムを選択できるようにしました。速度重視のものや見た目重視な物で5種用意しました。

**#1 None - 処理なし**：これは実機で表示できません。エフェクトとしてレトロPC感が欲しい場合や手作業でドット絵をフィニッシュしたい場合のベース画像として使えるかと思います。

[![画像](https://assets.st-note.com/img/1763960832-aUkHeQ59Yv6ogcJMFdtbzPIl.png)](https://assets.st-note.com/img/1763960832-aUkHeQ59Yv6ogcJMFdtbzPIl.png?width=2000&height=2000&fit=bounds&quality=85)さすがに綺麗

**#2 Fast - 高速**：8ドット中出現の多い2色を使います。その他ドットは近いほうを使います。美しさは落ちますが、これで充分な事もあります。処理がダントツに早いので長尺の動画や普通にグリッチ系エフェクトに使うなど使いどころはありそうです。

[![画像](https://assets.st-note.com/img/1763960967-WE4mCgAPo28uR6FQfHex0rUp.png)](https://assets.st-note.com/img/1763960967-WE4mCgAPo28uR6FQfHex0rUp.png?width=2000&height=2000&fit=bounds&quality=85)味はある

**#3 Basic - 基本**：横8ドット中の2色で候補を探す時に出現回数だけでなく色の距離も考察に含めます。

[![画像](https://assets.st-note.com/img/1763961129-fxRamD0HoTwF53QlnKL7GUEu.png)](https://assets.st-note.com/img/1763961129-fxRamD0HoTwF53QlnKL7GUEu.png?width=2000&height=2000&fit=bounds&quality=85)エラー色が少なくなります

**#4 Best**：こちらがお勧めの設定です。MSX1エフェクトは1度横8ドット内2色制限のない状態で絵を作ってから、横8ドット内2色への調整対応をしますが、後者の段階で再度基本15色から最小誤差ペアを見つける計算をします。（横8ドット内にない色が最終代表２色になりうります。）基本より賢いですが2度手間なのでちょっと遅くなります。

[![画像](https://assets.st-note.com/img/1763962830-2UMN6pchxLiJybgA9fIKmB3o.png)](https://assets.st-note.com/img/1763962830-2UMN6pchxLiJybgA9fIKmB3o.png?width=2000&height=2000&fit=bounds&quality=85)輪郭線などがきれいになる傾向

**#5 Best-Attr - BEST属性**：横8ドット内の代表2色を決める際に、少しだけ上下のドッと色も調整の計算に含めます。BESTの改良版の予定でしたが、この例ではむしろ汚くなっています。元絵によってはこちらの方がいい事もあるかもしれないので残してあります。

[![画像](https://assets.st-note.com/img/1763962871-sQR2jUWeGnrP3xwYKMHtdzCq.png)](https://assets.st-note.com/img/1763962871-sQR2jUWeGnrP3xwYKMHtdzCq.png?width=2000&height=2000&fit=bounds&quality=85)むしろ汚い

**#6 Best-Trans - BEST遷移**：横8ドット内の代表2色を決める際その隣の横ドットも調整計算に含めたものです。こちらもむしろ汚くなっていますが、同じ理由で残してあります。アニメ調ではない画像などではよい結果が得られるかもしれません。

[![画像](https://assets.st-note.com/img/1763963318-iSFNoXkqTrbGKB8JPRmv7MeY.png)](https://assets.st-note.com/img/1763963318-iSFNoXkqTrbGKB8JPRmv7MeY.png?width=2000&height=2000&fit=bounds&quality=85)むしろ汚い２

### RGB / HSB 色距離計算指定: Distance mode

色の近さの計算をRGBで行うかHSB（HSV)で行うかを切り替えられます。通常HSBの方がきれいですが、RGBの方がしっくりくる場合もあります。

[![画像](https://assets.st-note.com/img/1763963860-E57zUCPfLktn6MuWxrocZYKp.png)](https://assets.st-note.com/img/1763963860-E57zUCPfLktn6MuWxrocZYKp.png?width=2000&height=2000&fit=bounds&quality=85)RGB距離で計算した例

### HSB空間距離計算の重みづけ: H weight / S weight / B weight

色距離計算がHSBの場合のみスライダーで各項目の重みづけができます。Hが色あい、Sが彩度、Bが輝度です。

[![画像](https://assets.st-note.com/img/1763964062-vyDHK3TZAt9sWYe16g02RhQr.png)](https://assets.st-note.com/img/1763964062-vyDHK3TZAt9sWYe16g02RhQr.png?width=2000&height=2000&fit=bounds&quality=85)

デフォルトでは H:1, S:0.5, B:0.75 になっています。Hを下げるとあまりいい事はないですが他のパラメータ変更後の調整に使えたり、表現したい内容によってはワークします。色の明暗を重視したい場合にBを上げます。Sを変更するとかなり見た目が変わります。以下はSを下げてBを上げた例です。

[![画像](https://assets.st-note.com/img/1763964928-u0MBUzI8L7QroAtDTYph2fjk.png)](https://assets.st-note.com/img/1763964928-u0MBUzI8L7QroAtDTYph2fjk.png?width=2000&height=2000&fit=bounds&quality=85)

### Pre1 Satuation boost：彩度上げ

前処理で彩度を上げたほうが変換後の絵の表現が上がるのでデフォルトで少しばかり上げてあります。以下はOFFにした例です。

### Pre2 Gamma (darker)：暗部の強調

MSX1のCGは暗部のグラデーションが苦手です。思い切って黒に寄せてしまったほうがきれいになる事が多いです。また、黒い線画もこれをONにしたほうが強調されます。デフォルトでONです。
最初の前処理の例でトーンカーブを変更していましたが、主にこの目的で変更していて、Pre 2 設定がONでも足りていなかったので対応した感じになります。以下はOFFにした例です。

[![画像](https://assets.st-note.com/img/1763966083-BTSmfUEZ9PDOYliIRGVyFnh6.png)](https://assets.st-note.com/img/1763966083-BTSmfUEZ9PDOYliIRGVyFnh6.png?width=2000&height=2000&fit=bounds&quality=85)街並みの黒い部分や女の子の輪郭線が減っています

### Pre3 Highlight adjust: 明部の強調

MSX1のCGでは白い部分も思い切って飛ばしてしまったほうが余計なディザ表現がなく綺麗な事が多いです。この処理がデフォルトでONになっています。以下はOFFにした例ですが、この元画像の場合はあまりどちらが良いという差は見られません。

### Pre4 Skin tone bias: 肌色の調整

肌色がきれいに出るような調整をくわえるものですが、デフォルトでOFFです。肌色が多岐にわたるので適用が難しいですが、調整でONにしてみる価値はあります。以下はONにした例です。今回の例ではONにしても背景が変化するのみでした。

## 色味の最終調整

ここまでMSX1パラメータをエフェクトのパラメータで調整したうえで、まだ気になる部分は AE / プレミアの前処理の設定を微調整します。ここでは肌色がもっときれいに出るようにカラーホイールでMIDトーンを調整してみました。

## 動画書き出し

ここまで静止画として処理してきましたが、元素材は動画なのでこのまま残りのフレームも同じ設定のMSX1エフェクトをかけて動画出力できます。1枚絵で出力して、ドットの手作業によるクリンナップに入るのも良いですね。

元動画は30FPSなんですが、ドット絵がぬるぬる動だと違和感があるので（それはそれで新しい表現としていいのですが今回は）FPSを下げます。ポスタリゼーション時間というエフェクトがあるのでこれを色彩調整前に差し込んで、FPSを12にします。（12は2でも3でも4でも割り切れるリミテッドアニメーション的に良い数字です。）

現在は256*192の改造ですがSNSに上げるには小さすぎて、そのままだと拡大再生時にボケボケになるので、整数倍に拡大します。大きくしすぎてもドット絵として見づらくなるので個人的には3~倍を推奨しています。また、動画サイズの比率は16:9にするのが良いです。

Youtube向けにFHD1920x1080サイズ動画内に3倍拡大して配置します。アンチエイリアスの設定をOFFにしないと拡大時にドット絵が壮大にぼやけるので注意です。全体のFPSは12のままでもいいかもしれませんが、通常の動画に合わせて倍の24にします。

[![画像](https://assets.st-note.com/img/1763971239-bSC5sQ7g0PdtHXTGa3rp4fz1.png?width=1200)](https://assets.st-note.com/img/1763971239-bSC5sQ7g0PdtHXTGa3rp4fz1.png?width=2000&height=2000&fit=bounds&quality=85)

レンダリングの設定は"ドラフト"にします。"最高"設定のままだとドット絵がぼやけてしまいます。
