タイトル長いよ。（ヘッダー画像およびサンプル画像の元データ： プリンセスメーカー © 1992 ガイナックス / マイクロキャビン。）

### スクリーン２生データ書き出し

CLIツールにスクリーン２のVRAM生データ書き出し機能が付きました。(フル画面使うのでスクリーン1.5的な何かじゃなくて2そのもので良かった）

```
.\msx1pq_cli.exe -i .\hoge.png -o .\result\ --out-sc2
```

みたいに --out-sc2 オプションでpngの代わりにsc2ファイルが書き出されます。これはBASICで **SCREEN 2:BLOAD "HOGE.SC2", S** のような形で表示できます。

もしすでにエフェクト適用済みのpngを改めてsc2化したい場合は

```
.\msx1pq_cli.exe -i .\moge.png -o .\result\ --out-sc2 --distance rgb --no-preprocess
```

のように **--distance rgb** と **-no-preprocess**オプションを併用してください。これをしないと出力結果が大きく変わってしまいます。

### スクリーン5生データ書き出し

同様にスクリーン5の生VRAMデータとしてMSX1エフェクトのかかった画像を書き出すことができます。さてこれがなぜ必要なのか？

```
.\msx1pq_cli.exe -i .\hoge.png -o .\result\ --out-sc5
```

## ビューアー付きのdskイメージが作れます

BLOADやらパレットの設定を毎回するのが面倒くさいので、BASICでビューアーを作りました。今回C++よりもPythonよりも一番苦労したのがBASICコードの記述です😇
さらにツールからビューアーとVRAMイメージを詰め込んだdskイメージを作れるようにしました。配布物の中に **basic_sc2_viewer.exe** が含まれているのでこれを使います。

```
basic_sc2_viewer.exe sc2やsc5が含まれるフォルダ -o 出力ファイル名.dsk
```

これでビューワーとsc2 / sc5 ファイル入りのディスクイメージを作成できます。デフォルトではMSX2以降ではsc2 / sc5 両方、MSX1では sc2のみが表示されますが、オプションでMSX2でsc2を表示しない設定もできます。

```
.\basic_sc2_viewer.exe -h

options:
  -h, --help            show this help message and exit
  -o OUTPUT, --output OUTPUT
                        Output Diskimage(*.dsk) path
  -s2m2 ALLOW_SC2_IN_MSX2, --allow-sc2-in-msx2 ALLOW_SC2_IN_MSX2
                        allow sc2 files to be viewed on MSX2 machines.
```
