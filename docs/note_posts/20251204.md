# MSX1CGビューアーをwebMSXで自動実行する

今回は、先日つくったsc2形式のCGビューアーをwebMSXで自動起動するこころみです。 [webMSXを起動！ ](https://webmsx.org/?m=MSX1&DISKA_URL=https://github.com/harayoki/MMSXX_samples/raw/refs/heads/main/docs/dsk/sample_images_2512_1.zip?download&SCREEN_FILTER_MODE=2&SCREEN_DEFAULT_SCALE=1.5&Z80_CLOCK_MODE=8&VDP_CLOCK_MODE=8&VDP_PALETTE=2&SCREEN_DEFAULT_ASPECT=1.14) ← クリックするとMSX1 CGがwebMSXで表示されます。CG4枚入れておきました。スペースキー/下キーで次の絵に、上キーで前の絵に進みます。1枚16kなので2DDディスクだと40枚以上入りますね。やったぜ。

はい、webMSXの見ため関連の機能はよくとても良くできていて、微妙な色合いのMSX１パレットの再現はもちろん。1ピクセルの比率が1.14:1の横長で表時ができ（１：１にもできます）CRT系のフィルターも充実しています。CGのビューアーとして使うというのはありではないかと思いました。

### からくり

先のリンクの実際のパラメータ付きURLはこんな感じです。

[https://webmsx.org/?m=MSX1&DISKA_URL=https://github.com/harayoki/MMSXX_samples/raw/refs/heads/main/docs/dsk/sample_images_2512_1.zip?download=&SCREEN_FILTER_MODE=2&SCREEN_DEFAULT_SCALE=1.5&Z80_CLOCK_MODE=8&VDP_CLOCK_MODE=8&VDP_PALETTE=2&SCREEN_DEFAULT_ASPECT=1.14](https://webmsx.org/?m=MSX1&DISKA_URL=https://github.com/harayoki/MMSXX_samples/raw/refs/heads/main/docs/dsk/sample_images_2512_1.zip?download&SCREEN_FILTER_MODE=2&SCREEN_DEFAULT_SCALE=1.5&Z80_CLOCK_MODE=8&VDP_CLOCK_MODE=8&VDP_PALETTE=2&SCREEN_DEFAULT_ASPECT=1.14)

githubにおいた生ファイル（dskイメージをZIP圧縮したもの）をwebMSXに渡して自動でエミュレーターのMSX1に読み込ませています。ディスクにはAUTEXEC.BASが仕込んであるのでBASICの製のSC2ファイルビューアも自動起動します。

あと禁断技？ですが、**Z80とVDPを8倍のクロックアップ**指定してwebMSXを動かしています！起動もディスクアクセスも動作もサクサクですね😝MSX1＋ディスクと言うのもレアな感じですが、ビューアーとしてシェアするならこれでいいんじゃないでしょうか。

通常の速さ（遅さ？）を体験したい人はこちらをどうぞ。
