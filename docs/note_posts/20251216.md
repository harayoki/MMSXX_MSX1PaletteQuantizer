# MSX1 Palette Quantizer AE / Premiere プラグイン & CLI v0.8b

After Effects / Premiere Pro で MSX1ルールのドット絵エフェクトを再現するプラグインとそのCLI版の最新仕様まとめです。

最新版のダウンロードは GitHub Releases で配布しています。
https://github.com/harayoki/MMSXX_MSX1PaletteQuantizer/releases

以前の投稿(v0.2a相当の解説)からの変更点のみ記述します。以前の投稿はこちらです。

https://note.com/harayoki/n/nef7d2f9b5380

## AE / Premiere Pro プラグイン版

* スマートレンダリングに対応：高速化！
* マルチフレームレンダリングに対応：高速化！
* 15色パレットを個別に無効化するオプション追加 / ランダムで１色ずつの増減も可能に。

![yanone_07.png](yanone_07.png)

## CLI版

* 15色パレットを個別に無効化するオプション追加。
* screen2の生バイナリ出力に対応 （一時あったscreen5出力は廃止）。
* 前処理でLUTを適用可能。
* 出力画像の接頭語を指定できるように。
* 出力画像の接尾語を指定できるように。
* 前画像処理をOFFにするオプション追加 (すでに色調整済みの素材をsc2に変換する場合などに使う)。

## プラグイン版 / CLI版 共通

* 前処理でポスタリゼーションを追加 色の揺らぎを押さえる。
* 前処理で色相の回転が可能に。
* 前処理の彩度、ガンマの設定が強度指定可能に。一般的な画像編集ソフトに近い挙動に変更。
* 前処理にコントラスト設定を追加。
* MSX1パレット化前の内部状態 92色出力が可能に（開発用＆手作業でCGを作る人向け）。
* Color Distance は RGB がデフォルトに。
* HSV Weight と同様に RGB Weight で色距離計算の重みづけを個別に調整可能に。

## 実機：エミュレータ向け 

* ビューワー入りdskイメージを作成可能
* ビューワー入り32k ROMイメージを作成可能

## その他

Linux向け CLI版 ビルド設定を追加。ビルド成功まで確認済み。
