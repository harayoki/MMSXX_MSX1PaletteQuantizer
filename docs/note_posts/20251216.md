# MSX1 Palette Quantizer プラグイン最新版（2025年12月16日版）

After Effects / Premiere Pro で MSX1 の8ドット2色制限を再現するプラグインの最新仕様まとめです。Python CLI 版と同じコアを使い、前処理・パレット制御がすべてエフェクト内で完結します。最新のダウンロードは GitHub Releases を参照してください。

## インストールと適用の流れ

1. 配布ZIPを解凍し、各アプリの Plug-ins フォルダへコピーします。
2. 256x192 を基準にしたコンポジションに素材を配置し、レイヤーの補間を「ニアレストネイバー」に変更します。
3. エフェクトメニューから **MSX1 Palette Quantizer** を適用します。

## 主要パラメータ（最新版）

### メイン設定

- **Color system (MSX1 / MSX2)**: 15色パレットを切り替え。
- **Dither / Dark Area Dither**: ディザのON/OFFと暗部専用ディザの使用有無。
- **8-dot / 2-color**: 横8ドット内の代表2色を選ぶアルゴリズムを選択。
- **Color Distance**: RGB / HSV から距離計算モードを選択。
- **RGB Weight / HSV Weight**: 距離計算の重みを各成分ごとに調整。

### 前処理スライダー

- **Posterization**: 0で無効。値を上げると事前に色段数を減らし、ディザの出方を整えます。
- **Saturation Boost**: 0で無効。値に応じて彩度を強調（1でおおよそ+25%）。
- **Gamma (Darker)**: ガンマ値を直接指定。1で変化なし、1より大きいと中間調が暗くなります。
- **Contrast Adjust**: 1で変化なし。上げるとコントラスト強化、下げると抑制。
- **Hue Rotate**: -180〜180°で色相を回転。

### パレットコントロール

- 16色（透過含む）のうち、使う色だけをチェックボックスで選択可能。外した色は量子化対象から除外されます。
- **Randomize / Rand +1 / Rand -1** ボタンで、使用色の組み合わせをランダムに入れ替えたり、現在のセットから1色増減したりできます。
- 上部のスウォッチは見本表示で、クリックして色を変更することはできません。

## 推奨ワークフロー

1. 素材のトーンカーブやLUTでベースの色味を整える。
2. 前処理スライダーで彩度・ガンマ・コントラストを微調整。
3. パレットコントロールで使う色を絞り、ランダムボタンで候補を探る。
4. 8-dot/2-color アルゴリズムを切り替え、ディザ設定を調整して仕上げ。
